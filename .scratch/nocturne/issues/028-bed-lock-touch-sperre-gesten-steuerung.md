# 028: Bed-Lock Touch-Sperre & Gesten-Steuerung

**What to build:**
Vollbild-Touchsperre (Bed Lock) gegen versehentliche Eingaben durch Bettdecke, Kissen oder Beruehrungen im Halbschlaf.

**Blocked by:**
TICK-027

**Phase:** Phase 5: UI & Bedtime Player
**Type:** Feature | **Layer:** Presentation / Lock | **Points:** 3 | **Priority:** P1
**Status:** ready-for-agent

**Acceptance criteria:**
- [ ] Ein-Klick Aktivierung der Bildschirmsperre im Player.
- [ ] Deaktiviert alle normalen Touch-Gesten waehrend der Sperre.
- [ ] Entsperren erfordert bewusste Geste (langes Druecken von 2 Sekunden oder Wischgeste).
- [ ] Gedaempfte Bildschirmanzeige waehrend Bed-Lock aktiv ist.

**Verification method:**
Gesture & Lock Widget Tests
